# Детекция ботов-парсеров, кейс Авито

Score от 0 до 1 для каждой `cookie_id` из test. Метрика: Precision при Recall >= 70%.
Результат: 0.873 на скрытом тесте при 0.094 у константы, на CV по времени 0.86-0.88.

## Подход
1. Очистка: берем только события внутри окна. В train есть события после окна, включая всю капчу,
   это утечка. Удаляем дубли, приводим `platform` к трем значениям, сортируем по времени.
2. 119 поведенческих признаков: паузы между событиями, курсор, листание выдачи, состав событий,
   возраст куки, тип клиента из User-Agent.
3. Граф общих объявлений: боты одного сервиса ходят по общему списку объявлений. Берем только прошлые
   дни и текущий, метки других кук не используем.
4. Второй уровень модели добавляет оценки соседей по графу, метка самой куки в них не попадает.
5. Модель: LightGBM + CatBoost, по 3 сида.

Валидация по времени: учим на прошлых днях, проверяем на следующих. Эксперименты в `solution.ipynb`.

## Запуск
Python 3.14.6, данные кейса положить в `./data`.
```
pip install -r requirements.txt
python make_submission.py      # пишет submission.csv
```
Библиотеки: numpy, pandas, scikit-learn, LightGBM, CatBoost, matplotlib. XGBoost нужен только для сравнения моделей.
